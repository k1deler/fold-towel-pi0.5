## 6. 实验室现场启动

通过已有流程停止旧ACT/DP/WebUI/遥操作对设备的占用。无需打开WebUI。在现场有人看护的实验室终端执行：

```bash
cd "$HOME/kideler_deploy/fold_towel_pi05_frontend_20261103"
bash scripts/run_robot.sh
```

这是人工现场命令；开发或训练检查不会替你远程执行它。务必在操作包根目录运行，不直接进入`inference`调用同名脚本。

程序初始化设备后会按原流程移动到训练集示教起始姿态，再等待Enter。按键沿用旧程序，终端按行读取：

| 输入 | 行为 |
|---|---|
| Enter | 开始本轮；运行中再次Enter暂停；再次Enter恢复 |
| r，再Enter | 结束本轮，回到起始姿态，等待下一轮Enter |
| q，再Enter | 结束并按原流程归位、退出，释放设备 |
| Ctrl+C | 按原软件清理流程退出；可能包含归位运动，不是硬件急停 |

每轮最长40秒，双臂运动，原速度和硬件watchdog保留。机器人侧继续100Hz伺服，模型每次输出50步、30Hz动作，默认每30步重新规划。夹爪绝对目标在两端都校验并限制到[0,1]，12关节已经由模型适配器还原，不能再次加当前姿态。

断连、错误模型或过期预测会结束本轮并进入原清理流程；有故障时不会自动清除或重开控制会话。若软件无法完成清理，按实验室现场停止流程处理。

## 7. 停止顺序

先在机器人终端输入`q`再Enter，等归位和退出完全结束。然后在模型服务终端Ctrl+C，最后关闭两个SSH隧道窗口。不要把停止模型服务或关隧道当作机械臂停止命令。
