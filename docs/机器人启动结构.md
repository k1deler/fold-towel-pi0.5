# 真机启动结构约定

用户要求沿用已运行成功的ACT/fufu操作结构。保持独立目录、安装入口、自检、scripts/run_robot.sh、原操作员按键、双腕相机、100Hz伺服、回起始姿态和退出清理方式。

按键必须沿用现有YAM运行器：Enter开始或暂停/恢复；r加Enter结束本轮并回到示教起始姿态；q加Enter归位退出。Ctrl+C按原清理流程处理，不描述为硬件急停。不得以本说明称已有π0.5真机程序通过验证。

实现时采用独立π0.5推理进程，原YAM运行器继续负责设备与伺服。模型服务只推理，不初始化相机或机械臂。ACT入口保持原样。π0.5输出经训练期相同Unnormalize和FoldOutputs还原后已经是物理绝对目标，禁止再次给14维加当前姿态。12个关节相对同一次观测还原，两个夹爪为绝对目标。

图像维持原480x640 RGB和录制JPEG质量90预处理；模型输入使用原OpenPI保比例resize到224和掩码，不能先缩放成ACT小图。进程间传图须用无损编码，避免额外JPEG引入第二次有损压缩。缺失base图像维持黑图和false掩码。

时间戳仍以相机观测时刻对齐从臂状态，offset0，H50、30Hz；超过49/30秒才返回的动作不能当作新鲜计划执行。原速度约束、硬件占用检查、夹爪[0,1]裁剪与伺服停止流程继续保留。离线指标保留未经裁剪的越界率，不能裁剪后再报告无越界。

交付前必须先通过保留观测回放：模型、统计、关节顺序、动作还原、夹爪越界处理、时间对齐与连接断开行为均需测试；在此之前不生成已通过的部署凭证，不远程启动机器人。当前只完成结构约定和离线评估队列，实机适配尚未实现。
